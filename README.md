# Electric Vehicle Dashboard using Tableau

## Project Overview
This project analyzes Electric Vehicle (EV) data using Tableau to understand EV adoption, vehicle trends, and market growth.

## Tools Used
- Tableau
- Excel

## Project Objectives
- Analyze electric vehicle adoption.
- Understand EV distribution by vehicle type.
- Identify popular EV manufacturers.
- Analyze EV growth trends.

## Dashboard Features
- Interactive Dashboard
- KPI Cards
- Charts and Visualizations
- Filters and Parameters

## Conclusion
This project helped me improve my Tableau skills, data visualization techniques, dashboard development, and data analysis abilities.
